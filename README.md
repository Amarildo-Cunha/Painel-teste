# Painel Teste

App (página instalável) para testar painel Scania em bancada pelo celular Android, via Bluetooth (BLE), conversando com o firmware `Painel_Teste_v0.6` no ESP32.

Abrir no Chrome do Android: https://amarildo-cunha.github.io/painel-teste/ → menu ⋮ → **Instalar app**. Depois de instalado funciona sem internet.

Só contém a página do app (sem firmware nem dados).
